Cinder Wallet

Privacy Policy

Last updated: 14 September 2026

Cinder Wallet is a browser extension. The seed phrase and private keys are encrypted on this device. We do not operate a backend that receives your seed, password, or private keys.

What stays on your device

  • Encrypted vault (seed phrase) in chrome.storage.local
  • Unlocked session seed material in chrome.storage.session until you lock or the browser closes
  • Settings such as auto-lock and network, and any custom RPC URL or Helius API key you enter in Settings

What leaves the device

  • Public addresses and signed transactions sent to a Solana JSON-RPC endpoint. With nothing configured, Mainnet uses https://solana-rpc.publicnode.com and Devnet uses https://api.devnet.solana.com
  • A custom RPC URL or Helius API key you enter in Settings receives the same public addresses and signed transactions. Both values are stored only in chrome.storage.local on this device; we never receive them
  • Your public wallet address sent to https://lite-api.jup.ag on Mainnet, and only when you have configured neither a custom RPC URL nor a Helius API key. The public Mainnet endpoint refuses to list token accounts, so without this the wallet can show SOL only. Jupiter is asked which mints the address holds and what those mints are called; the balances, decimals and token programs shown are read from the Solana endpoint, never from Jupiter. Entering any RPC URL or Helius key in Settings stops this request being made at all, and it is never made on Devnet
  • Public mint addresses sent to CoinGecko for USD prices on mainnet only
  • dApp origins you approve, which see the public addresses you connect
  • Token and collectible images load directly from whatever host the token's own metadata names (commonly IPFS or Arweave gateways, or a project's own server). Those hosts see the request and your IP address; Cinder does not choose them and does not proxy them
  • Viewing a collectible fetches its metadata document, and then its image, from whatever host that collectible's creator named in its on-chain metadata. Those hosts see the request and your IP address; Cinder does not choose them, does not proxy them, and sends no cookies or wallet address with the request. Nothing is fetched until you open the collectibles tab, and only for the items shown on screen
  • Opening a transaction in the explorer hands off to https://solana.fm in a new tab, which receives that transaction signature. Nothing is sent there unless you click the link

What we do not do

  • We do not sell or rent personal data
  • We do not use your wallet data for advertising
  • We cannot recover a forgotten password or a lost seed phrase

Chrome Limited Use

Data read from the browser is used only to provide wallet functionality: encrypting the vault, showing balances, and signing transactions you approve. It is not transferred to third parties except the RPC, token-list and price providers named above, and only as needed for those features.
