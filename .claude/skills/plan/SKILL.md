# /plan

1. Read the ticket or request. Research the existing code; do not invent APIs.
2. Write `docs/plans/<ID>-<slug>.md` from `docs/plans/TEMPLATE.md`.
3. Steps must name 2–5 files and their own verification (`just check`, `just ext`, or a targeted `just test`).
4. Stop for approval. Write no application code.
